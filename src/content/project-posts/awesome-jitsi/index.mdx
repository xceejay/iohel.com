## A Curated List of Jitsi Resources

[Awesome Jitsi](https://awesome-jitsi.com) is a community-maintained collection of the best resources, tools, services, and guides for the Jitsi ecosystem. It follows the "awesome list" format popularized on GitHub and has earned **51+ stars**.

### Categories

- **Documentation** including the official handbook, Easy Jitsi docs, and Jibri tutorials
- **Installation** with Docker-based deployments and one-line installers
- **Security** covering end-to-end encryption, LDAP, and saslauthd authentication
- **Services** like platforms and integrations built on top of Jitsi (Call Stats, Rocket Chat, Veertly)
- **Testing** with WebRTC interoperability testing tools like TestRTC and KITE

The goal was to make the Jitsi ecosystem more accessible. When I was working on Jitsi deployments, I kept finding useful tools scattered across GitHub, blog posts, and forums. This list brings them all together.
